Q1.  4 Marks

List the names of employees that made sales on September 23, 2014.


a.	Using standard syntax

SELECT st.Lastname
FROM Staff st, Sales s
WHERE s.StaffNo = st.StaffNo AND s.SaleDate = '2014-09-23'
GROUP BY st.Lastname;


b.	Using syntax 1999

SELECT st.Lastname
FROM Staff st JOIN Sales s
	ON s.StaffNo = st.StaffNo
WHERE s.SaleDate = '2014-09-23'
GROUP BY st.Lastname;


Q2.  3 Marks

Display the name of McLester’s supervisor


a.	Using standard syntax

SELECT ss.Lastname
FROM staff ss, staff s
WHERE ss.StaffNo = s.SupervisorNo AND s.lastname = 'McLester';


b.	Using a subquery

SELECT Lastname
FROM staff 
WHERE StaffNo =
				(SELECT SupervisorNo 
				FROM staff
				WHERE lastname = 'McLester');


Q3.  4 Marks

Which items are part of order number 020011? 
Display item name (DESCRIPT, INVENTORY), and sale price (SALEPRICE, INVENTORY)

SELECT n.Descript, n.SalePrice
FROM inventory n, items t

Q4. 4 Marks

Display the total amount on sales and the corresponding commission of Michaels (staff name)


a.	Using standard syntax

SELECT SUM(n.SalePrice*t.Qty) AS 'Total Sales Made by Michaels', SUM(s.Commission) AS 'Michaels Comission'
FROM inventory n, items t, staff s, sales l
WHERE n.partNo = t.partNo AND s.staffNo = l.staffNo AND l.orderNo = t.orderNo AND s.lastname = 'Michaels'
GROUP BY s.commission;


b.	Using syntax 1999

SELECT SUM(n.SalePrice*t.Qty) AS 'Total Sales Made by Michaels', SUM(s.Commission) AS 'Michaels Comission'
FROM inventory n JOIN items t JOIN staff s JOIN sales l
	ON n.partNo = t.partNo AND s.staffNo = l.staffNo AND l.orderNo = t.orderNo
WHERE s.lastname = 'Michaels'
GROUP BY s.commission;

Q6.  4 Marks

Find all sales done in September. Display order number, sales date and staff member name. 

a)	Use standard syntax

SELECT l.OrderNo, l.SaleDate, s.lastname
FROM sales l, staff s
WHERE l.staffNo = s.staffNo AND MONTH(l.SaleDate) = '09';


b)	Use syntax 1999

SELECT l.OrderNo, l.SaleDate, s.lastname
FROM sales l JOIN staff s
	ON l.staffNo = s.staffNo 
WHERE MONTH(l.SaleDate) = '09';

Q8.  4 Marks

Create a query to calculate all purchases of customer number 100019. The output of this query should be order number, part number, part description, quantity, sale price, and total amount per Item (Format the result to currency and two decimal places). 

a)	Use standard syntax

SELECT t.orderNo, t.partNo, n.descript, t.qty, n.saleprice, CONCAT('$',FORMAT(n.SalePrice*t.Qty,2, 'en-US')) AS 'Total$'
FROM items t, inventory n, sales l
WHERE t.partNo = n.partNo AND t.orderNo = l.orderNo AND l.custNo = '100019';


b)	Use syntax 1999

SELECT t.orderNo, t.partNo, n.descript, t.qty, n.saleprice, CONCAT('$',FORMAT(n.SalePrice*t.Qty,2, 'en-US')) AS 'Total$'
FROM items t JOIN inventory n JOIN sales l
	ON t.partNo = n.partNo AND t.orderNo = l.orderNo 
WHERE l.custNo = '100019';


Q9.  4 Marks

In the table Inventory the items that are discontinued appear under the field name DISCONTINUE with a value of 1. Write a query to find out the Customer number of those customers that have ordered items that have been discontinued.

a)	Use standard syntax

SELECT l.custNo 
FROM sales l, inventory n, items t 
WHERE t.partNo = n.partNo AND t.orderNo = l.orderNo AND n.discontinue = '1';


b)	Use syntax 1999

SELECT l.custNo 
FROM sales l JOIN inventory n JOIN items t 
	ON t.partNo = n.partNo AND t.orderNo = l.orderNo 
WHERE n.discontinue = '1';
